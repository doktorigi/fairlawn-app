# Fair Lawn Resident Guide

Installable web app (PWA) for Fair Lawn, NJ: news, events, garbage & recycling, schools, programs, parks map, businesses, contacts.

- `data/gov.json`, `schools.json`, `parks.json`, `local.json`: curated, researched content (edit these; each also lists the `feeds` to poll).
- `data/feed.json`: generated by `tools/update_feeds.py` (stdlib Python) from ~30 RSS/iCal feeds: Nixle alerts, district + school calendars, library, Google News, Patch, Main Street, Reddit.
- `.github/workflows/update.yml`: refreshes feeds every 3 h and deploys to GitHub Pages.

Run locally: `python tools/update_feeds.py && python -m http.server` then open http://localhost:8000.
Parser self-check: `python tools/update_feeds.py --test`.

Facebook groups and Nextdoor have no public feeds; they're linked under Explore → Community.
